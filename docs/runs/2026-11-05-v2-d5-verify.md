## Reading

- Every metric is identical to the D4 record `20261105T093948Z` and the pinned
  D3 baseline: Hit@5 0.76, judge correct 12/15, faithful 12/15, abstention 10/10.
- D5 is flat because the failure mode it targets did not occur. This is a real
  negative result for the retry on this gold set, not a regression.
- The retry is a guardrail against a generator that answers without citing. It is
  unit-tested on that path (empty draft, uncited draft, budget exhaustion,
  refusal-final, reset ordering, SSE retry), but the eval cannot exercise it
  until a run produces an uncited draft.
- Cost and latency are unchanged in this run: no extra generation calls. The
  worst case remains one extra draft per failed verification, capped by
  `OWL_RETRY_BUDGET`.
- The weak slice is still multi-part: Hit@5 0.62 and faithfulness 2/5. That is a
  retrieval problem, so the next quality lever is #79, not more generation
  retries.
- A useful follow-up for the harness is a synthetic uncited response, so the
  retry trigger can be measured without relying on a real model failure.
